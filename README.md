# Employee Attrition Analysis

## Overview

This project predicts employee attrition using Machine Learning and analyzes factors that influence employee turnover.

## Technologies Used

* Python
* Google Colab
* Pandas
* Seaborn
* Matplotlib
* Scikit-Learn

## Features

* Employee Attrition Analysis
* Age and Salary Analysis
* Department-wise Attrition Analysis
* Random Forest Classification
* Employee Attrition Prediction
* Feature Importance Visualization

## Dataset

IBM HR Analytics Employee Attrition Dataset

## Model

Random Forest Classifier

## Result

Successfully identified key factors affecting employee attrition and predicted employee turnover with machine learning techniques.
